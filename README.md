# Divination Notes

这个仓库整理了一批与传统术数、命理分析、古典占星和 AI 辅助解读相关的中文笔记与讲稿。内容主要来自荀爽 Bilibili 往期直播，以及星阙公众号文章；同时也包含围绕 AI 提问、命盘信息组织和不同流派参考方式整理出的使用笔记。

这些资料更适合作为“提示词背景材料”或“知识库参考”使用：当你把它们与具体命盘、出生信息、起卦信息、限运信息等一并输入 AI 时，模型通常能给出更贴近术数语境、更有结构感的回答。

## 适合怎么用

可以把本仓库中的笔记当作 AI 解盘时的上下文资料。例如：

1. 先提供具体命盘信息，如八字、紫微斗数盘、六爻卦、小六壬课式、古典占星星盘或主限法资料。
2. 再附上相关笔记全文或节选，说明希望 AI 按照这些资料中的术语、判断逻辑和分析顺序来回答。
3. 明确提问目标，例如性格分析、流年判断、事业财运、关系互动、应期推断、取象思路复盘等。
4. 要求 AI 区分“根据资料可推断的部分”和“仅供参考的延伸判断”，这样回答会更稳。

## 使用建议

如果直接把“我是什么命”丢给 AI，回答往往会比较泛。更好的方式是把问题拆清楚：

- 提供完整的基础信息，而不是只给一个结论。
- 指定采用哪份笔记或哪套方法。
- 要求 AI 先列分析依据，再给判断。
- 对重要判断要求给出反证、限制条件和不确定性。
- 对同一命盘可以分别用八字、斗数、六爻、古典占星、星平合参等不同视角交叉验证。
